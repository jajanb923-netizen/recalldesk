Guided demo — the proof in two tickets

  1. Seed the desk. Three runbooks go into Meko's knowledge base. No fixes remembered yet.
  2. Ticket #1 — cold solve. "Login page times out on slow network". No memory hit: the resolver solves it from the runbook, saves the fix as a memory, and a reviewer approves it for promotion.
  3. Promote the fix (human gate) so it becomes shared knowledge.
  4. Ticket #2 — same issue, new words, new agent. "Users can't sign in — the login screen just hangs". The triage agent finds yesterday's fix in shared memory and answers without re-solving.

Every step below is a real Meko call (context_search, memory, knowledge base, conversations, artifacts) and a real Groq model call. Nothing is canned.
